# 作品001　お芋怪盗「ほくほく大作戦」ショートPV

テーマソングに合わせた横型のショートPV。動画工場（部品部の Remotion）で作る。

## ファイル
| ファイル | 中身 |
|---|---|
| 台本.md | 物語・登場人物・15場面の絵コンテ表 |
| timing.json | 場面ごとのコマ番号と歌詞。Remotion の組み立てでそのまま読む |
| 素材/theme.m4a | テーマソング（元動画から音だけ取り出したもの、65秒で切った） |
| 素材/jacket.png | 元動画の絵（ジャケット絵）。見た目の基準 |
| 素材/lyrics_original.srt | 元動画に入っていた歌詞の字幕 |

## 曲の調べ
- 長さ：音は 66.7秒。曲の本編は 0:64.3 まで、その後は無音
- 元動画の 0:62 から Gemini の終わりの札（gemini.google.com/music）になる → PV では使わない
- テンポ：150 BPM（拍の間隔を測ると 0.395秒、字幕の切り替わりも 3.2秒＝2小節ごとなので 150 で確定）
- 音量：0:32 あたりから一段大きくなる（サビ）
